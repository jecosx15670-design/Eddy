# Eddy@01567

这是基于 [CHOCCOri/-](https://github.com/CHOCCOri/-) 授权二次修改与再创作的版本。

## 主要功能

- 自定义主页昵称、头像和个人资料
- 创建梦角并设置名字、头像与角色资料
- 私聊与多人群聊模式
- 自定义群聊名称、头像、成员与群内昵称
- 字卡、朋友圈、梦笺、答案之书、MOON、KOMO 等完整功能
- 所有个人数据默认保存在访客自己的浏览器中

## 使用

直接打开 GitHub Pages 地址即可。首次进入时阅读使用公告，然后在 `CHAT` 中创建梦角或群聊。

更多来源说明见 [CREDITS.md](./CREDITS.md)。
